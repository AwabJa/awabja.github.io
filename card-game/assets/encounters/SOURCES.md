Artwork is imported as self-hosted transparent PNGs and dynamically selected by act in the production battlefield. Each is static, not an animation sequence. The run changes the named enemies, their portraits, HP/shield balance and ambient lighting; attack motion is the existing software choreography and does not create articulated limbs.
