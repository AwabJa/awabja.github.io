# Moonfall experimental imported art

Source: https://freegamesprites.com/en/packs/anime-portraits

The publisher lists the images as CC0. The images are 384x512 transparent PNGs and are static character illustrations, not animated or skeletal rigs. This is a source claim, not an independent rights audit.

Assets actor-0.png through actor-6.png correspond to warrior-knight-hero-anime, rogue-assassin-cloaked-anime, healer-priestess-serene-anime, mage-cryomancer-boy-anime, necromancer-bone-king-anime, necromancer-grave-maiden-anime and paladin-dark-anti-hero-anime respectively.

This experiment uses self-hosted illustrations and the existing painted castle backdrop. The browser suite tests real first-party URLs and card gameplay. Visual quality is still below the cinematic reference, particularly in animation, pose diversity and card readability. Do not treat this branch as approved for release.
