# Reward card artwork source

Six new full-body transparent 384×512 PNG illustrations imported for Moonfall's between-act deck-building rewards from the [FreeGameSprites anime portraits CC0 pack](https://freegamesprites.com/en/packs/anime-portraits). The catalog declares these files CC0, suitable for commercial use. This is the publisher's licensing declaration, not an independent chain-of-title audit.

These are static portraits; they are not animations. The import workflow verifies PNG signatures, image dimensions, and non-trivial byte sizes before storing the files as first-party game assets. Card illustration variety improves, but this change does not claim to replace the seven battlefield characters' missing animated poses.
